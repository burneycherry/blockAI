# blockAI 村づくり

Minecraft統合版（Bedrock）用のアドオンです。AI村人に仕事を与えて、村長として村を発展させます。

- 対応バージョン：26.51以降（Script API：`@minecraft/server` 2.10.0、`@minecraft/server-ui` 2.2.0）
- 実験的機能（ベータAPI）：不要
- 対応機種：iOS、Android、Windowsなど（統合版なら同じファイルで動きます）

## インストール（iPhone）

1. GitHubの **Releases** を開き、`latest-...` の中の `blockAI-v<バージョン>.mcaddon` をタップしてダウンロードします。
2. ダウンロードしたファイルを「Minecraftで開く」と、自動で読み込まれます。
3. ワールドの設定で、**ビヘイビアパック**に「blockAI 村づくり」を追加します（リソースパックも自動で追加されます）。

## テスト用の入れ方（iPad・何度も試すとき）

`.mcaddon` で読み込むと版ごとにパックが溜まっていくので、テスト中は開発用フォルダを使います。上書きするだけで新しい版になり、古い版を消したりワールドに付け直したりしなくてよくなります。

**最初の1回だけ**
1. Minecraftの 設定 → ストレージ で、blockAI（ビヘイビア・リソース）を全部消します。
2. ファイルApp →「このiPad内」→ Minecraft → games → com.mojang → minecraftWorlds → 試すワールドのフォルダを開きます。中の `behavior_packs` と `resource_packs` に入っている blockAI のフォルダを消します。
3. 下の「毎回」の手順でテスト版を入れます。
4. ワールドの編集 → ビヘイビアパック で「blockAI 村づくり テスト版」を使用中にします。

**毎回（新しい版が出たら）**
1. Releases の `blockAI-test-v<バージョン>.zip` をダウンロードし、ファイルAppでタップして解凍します。
2. 出てきた `blockAI_BP` を com.mojang の `development_behavior_packs` へ、`blockAI_RP` を `development_resource_packs` へ移動します。「置き換える」を選びます。
3. Minecraftでワールドを開き直します。中身の版は、村長メニューや、パックの説明文（「中身は v…」）で確認できます。

- テスト中は `.mcaddon` を読み込まないでください（同じパックが2つになり、どちらが使われるか分からなくなります）。

## 遊び方

1. 最初にワールドへ入ると **村長の杖** がもらえます。
   - クラフトでも作れます（エメラルド1個、棒2個を縦に並べる）。
2. 杖を使う（長押し）と **村長メニュー** が開きます。そこで「ここに村を作る」を選びます。
3. メニューの「**村の倉庫を置く**」で、見ている場所に倉庫（木張りのチェスト）を置きます。
   - 村レベルが上がると、置ける数（1 → 5個）と広さ（大きいチェスト 1 → 16個分）が増えます。1マスに同じ物を64個まで入れられます（チェストと同じ）。
   - 中身はどの倉庫でも同じです。村人は一番近い倉庫へ運び、ふたを開けてしまいます。
   - 倉庫をタップすると、取り出す・手に持っている物をしまう・持ち物をまとめてしまう、ができます（道具や防具など重ねられない物は入りません）。
   - 取り出すときは、持ち物の欄と同じアイテムの絵が出ます。
4. 「**村人を雇う**」で村人を呼びます。スポーンエッグでも呼べます。
5. 杖で村人を**タップ**して「職業を変える」を選びます。

| 職業 | 仕事 |
|---|---|
| 木こり（基本） | 村から半径32ブロック以内の自然の木を切り、苗木を植え直して、原木を倉庫へ運ぶ |
| 農家（農業パック予定） | 実った小麦、ニンジン、ジャガイモ、ビートルートを収穫して植え直し、倉庫へ運ぶ。空いている畑（耕した土）には倉庫の種をまく。新しく耕すことはせず、周りの作物と同じ種だけをまく |
| 石工・大工・鉱夫など | 今後の職業パックで追加予定 |

- 働くと経験値が貯まり、レベルが上がります（最大Lv10）。レベルが上がると作業が速くなり、一度にたくさん運べるようになります。

  | Lv | 必要経験値 | 1個あたりの作業時間 | 一度に運べる数 | 体力 |
  |---|---|---|---|---|
  | 1 | 0 | 1.00秒 | 32 | 20 |
  | 2 | 30 | 0.90秒 | 48 | 22 |
  | 3 | 90 | 0.80秒 | 64 | 24 |
  | 4 | 200 | 0.70秒 | 80 | 27 |
  | 5 | 400 | 0.60秒 | 96 | 29 |
  | 6 | 700 | 0.50秒 | 128 | 31 |
  | 7 | 1100 | 0.45秒 | 160 | 33 |
  | 8 | 1600 | 0.40秒 | 192 | 36 |
  | 9 | 2300 | 0.35秒 | 224 | 38 |
  | 10 | 3200 | 0.30秒 | 256 | 40 |

- Lv5・Lv8・Lv10 で職業ごとの**特技**を覚えます。

  | 職業 | Lv5 | Lv8 | Lv10 |
  |---|---|---|---|
  | 木こり | 葉っぱ払い：葉も片付け、リンゴ・棒・苗木を拾う | 植林名人：植え直した苗木に骨粉 | 倒木：木を丸ごと切り倒す（倒れるアニメーション付き） |
  | 農家 | 豊作：ときどき収穫量+1 | 緑の手：作物が少し育った状態から始まる | 一斉収穫：目の前3×3（9マス）の実った作物をまとめて刈り取る |

- 村長メニューの「村の設定」でテストモードをONにすると、Lv1から全部の特技を使えます。
- **体力**は一番高い職業レベルで増えます（上の表）。休んでいる間は少しずつ回復します。
- **夜**になると村に戻り、空いているベッドで寝ます（普通の村人が使っているベッドは避けます。ベッドが無ければ倉庫の前で休みます）。朝には全回復します。
- 村人が**倒れる**と、持ち物はその場に落ち、翌朝に元気になって倉庫の横に戻ってきます。「村の設定」でOFFにすると、倒れたら二度と戻りません。
- **見た目**：村人は男女20人（マッチョ3人を含む）のキャラクターから決まり、雇うと空いている人物が来ます。転職すると衣装だけが変わります（木こり：チェックのネルシャツとニット帽、斧／農家：麦わら帽子とオーバーオール、鎌）。村人メニューの「見た目を選ぶ」で変えられます。
- 経験値は**職業ごと**に記録されます。木こりLv2を農家に変えると農家Lv1から始まり、木こりに戻すとLv2の続きからです。
- 木こりは村人メニューの「木こりの作業設定」で、**苗木の植え直しをOFF**にできます（開拓用。苗木は倉庫に持ち帰ります）。「葉っぱのブロックも持ち帰る」をONにすると、葉っぱ払い（Lv5）のときに葉をブロックのまま持ち帰ります（初期はOFF）。
- プレイヤーの近く（40ブロック以内）では、村人が本当に歩いて作業します。遠くにいるときは、移動と作業を省略して素早く片付けます。
- 建物の柱などの原木は切りません。「自然の葉がついている木」だけを切ります。
- **村レベル**：倉庫への納品数で村レベルが上がり、仕事の範囲（村の中心からの半径）が広がります。

  | 村Lv | 納品数 | 半径 |
  |---|---|---|
  | 1 | 0 | 32 |
  | 2 | 500 | 40 |
  | 3 | 2000 | 48 |
  | 4 | 5000 | 56 |
  | 5 | 10000 | 64 |

- **職業ごとの仕事場**：村長メニュー「仕事場と立ち入り禁止エリア」で、職業ごとに働く場所（半径8〜32）を決められます（例：木こりは北の森）。
- **立ち入り禁止エリア**：登録した範囲（半径2〜24）では、村人が木を切ったり作物を刈ったりしません。
- **遠くにいても村を動かす**（村の設定、初期ON）：村と仕事場を常に読み込み、プレイヤーが離れていても村人が働きます。OFFにすると、プレイヤーから離れた村人は止まります（Minecraftの仕様）。
- 穴に落ちるなどして目的地に12秒近づけないと、目的地へワープして戻ってきます（落下ダメージも受けません）。

## マルチプレイ

アドオンを入れたワールドやRealms、サーバーに参加した人は、参加するときに自動でパックをダウンロードします。参加する人が自分でインストールする必要はありません。

## 開発

```sh
npm install
npm run check   # 型チェック＋JSON・構文チェック
npm run build   # dist/blockAI.mcaddon を作る
```

- `packs/BP`：ビヘイビアパック（村人の定義とスクリプト）
  - `scripts/core/`：村・村人・仕事の管理、メニューなど全職業に共通の部分
  - `scripts/jobs/`：職業の部品（1職業＝1ファイル）。`jobs/index.js` で読み込む
- `tools/gen-entities.mjs`：職業の枠（16個）ごとの村人・マーカーの定義、体力の段階を生成する
- `tools/gen-humans.mjs`・`tools/human-art.mjs`：村人20人×衣装の見た目（128x128のテクスチャ・モデル・アニメーション）を生成する
- `tools/gen-storehouse.mjs`：村の倉庫の見た目を生成する／`tools/gen-tree.mjs`：倒木の演出を生成する
- `tools/make-test.mjs`：テスト用zip（開発用フォルダに上書きする版）を作る

### 職業の追加方法

1. `scripts/jobs/` に新しいファイルを作り、`registerJob({ ... })` で登録する（`lumberjack.js` が見本）
   - `scan`：村の周りを調べて仕事（対象ブロックと立ち位置）を登録する
   - `work`：仕事を1単位こなす（成功したら true）
   - `skin`：衣装の番号（`tools/human-art.mjs` の `OUTFITS` に衣装を足す）、`reach`：作業を始められる距離
2. `jobs/index.js` に `import` を1行足す
- `packs/RP`：リソースパック（見た目と翻訳）
- どのブランチでもpushすると、GitHub Actionsが `.mcaddon`（配布用）と `blockAI-test-v<版>.zip`（テスト用）を作って Releases の `latest-<ブランチ名>` に置きます。
