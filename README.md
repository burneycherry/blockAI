# blockAI 村づくり

Minecraft統合版（Bedrock）用のアドオンです。AI村人に仕事を与えて、村長として村を発展させます。

- 対応バージョン：26.51以降（Script API：`@minecraft/server` 2.10.0、`@minecraft/server-ui` 2.2.0）
- 実験的機能（ベータAPI）：不要
- 対応機種：iOS、Android、Windowsなど（統合版なら同じファイルで動きます）

## インストール（iPhone）

1. GitHubの **Releases** を開き、`latest-...` の中の `blockAI-v<バージョン>.mcaddon` をタップしてダウンロードします。
2. ダウンロードしたファイルを「Minecraftで開く」と、自動で読み込まれます。
3. ワールドの設定で、**ビヘイビアパック**に「blockAI 村づくり」を追加します（リソースパックも自動で追加されます）。

## 遊び方

1. 最初にワールドへ入ると **村長の杖** がもらえます。
   - クラフトでも作れます（エメラルド1個、棒2個を縦に並べる）。
2. 杖を使う（長押し）と **村長メニュー** が開きます。そこで「ここに村を作る」を選びます。
3. チェストを置き、それを見ながらメニューの「**倉庫を登録**」を選びます。
4. 「**村人を雇う**」で村人を呼びます。スポーンエッグでも呼べます。
5. 杖で村人を**タップ**して「職業を変える」を選びます。

| 職業 | 仕事 |
|---|---|
| 木こり（基本） | 村から半径32ブロック以内の自然の木を切り、苗木を植え直して、原木を倉庫へ運ぶ |
| 農家（農業パック予定） | 実った小麦、ニンジン、ジャガイモ、ビートルートを収穫して植え直し、倉庫へ運ぶ。空いている畑（耕した土）には倉庫の種をまく。新しく耕すことはせず、周りの作物と同じ種だけをまく |
| 石工・大工・鉱夫など | 今後の職業パックで追加予定 |

- 働くと経験値が貯まり、レベルが上がります（最大Lv5）。レベルが上がると作業が速くなり、一度にたくさん運べるようになります。

  | Lv | 必要経験値 | 1個あたりの作業時間 | 一度に運べる数 |
  |---|---|---|---|
  | 1 | 0 | 0.95秒 | 24 |
  | 2 | 30 | 0.80秒 | 32 |
  | 3 | 90 | 0.65秒 | 40 |
  | 4 | 200 | 0.50秒 | 48 |
  | 5 | 400 | 0.35秒 | 56 |

- 経験値は**職業ごと**に記録されます。木こりLv2を農家に変えると農家Lv1から始まり、木こりに戻すとLv2の続きからです。
- 木こりは村人メニューの「木こりの作業設定」で、**苗木の植え直しをOFF**にできます（開拓用。苗木は倉庫に持ち帰ります）。
- プレイヤーの近く（40ブロック以内）では、村人が本当に歩いて作業します。遠くにいるときは、移動と作業を省略して素早く片付けます。
- 建物の柱などの原木は切りません。「自然の葉がついている木」だけを切ります。
- 穴に落ちるなどして目的地に12秒近づけないと、目的地へワープして戻ってきます（落下ダメージも受けません）。

## マルチプレイ

アドオンを入れたワールドやRealms、サーバーに参加した人は、参加するときに自動でパックをダウンロードします。参加する人が自分でインストールする必要はありません。

## 開発

```sh
npm install
npm run check   # 型チェック＋JSON・構文チェック
npm run build   # dist/blockAI.mcaddon を作る
```

- `packs/BP`：ビヘイビアパック（村人の定義とスクリプト）
  - `scripts/core/`：村・村人・仕事の管理、メニューなど全職業に共通の部分
  - `scripts/jobs/`：職業の部品（1職業＝1ファイル）。`jobs/index.js` で読み込む
- `tools/gen-entities.mjs`：職業の枠（16個）ごとの村人・マーカーの定義を生成する

### 職業の追加方法

1. `scripts/jobs/` に新しいファイルを作り、`registerJob({ ... })` で登録する（`lumberjack.js` が見本）
   - `scan`：村の周りを調べて仕事（対象ブロックと立ち位置）を登録する
   - `work`：仕事を1単位こなす（成功したら true）
2. `jobs/index.js` に `import` を1行足す
- `packs/RP`：リソースパック（見た目と翻訳）
- どのブランチでもpushすると、GitHub Actionsが `.mcaddon` を作って Releases の `latest-<ブランチ名>` に置きます。
