# 統合版・iOSで実際にハマった点

- iOS/iPad はファイル名ごとに読み込み結果を覚える。そのため、配布ファイル名に版を入れる（同じ名前だと古い版が読み込まれ続けた）
- manifest の name に `pack.name`（翻訳キー）を使うと、読み込み先のフォルダ名が毎回 `pack.name` になり、古いキャッシュと混ざった。name には版入りの文字列を直接書く
- ワールドは追加したときの版に固定される。更新したら新しいワールドで試すか、パックを付け直す
- 読み込んだパックは上書きされず、版ごとに別のパックとして溜まる（自動で入れ替わるのはマーケットプレイス品だけ）。さらにワールドのフォルダ内 `behavior_packs`/`resource_packs` にもコピーが残り、設定のストレージからは消せない。テストは開発用フォルダ（テスト用 zip）で行う
- client_entity の format 1.10.0 では `animation_controllers` は使えない（`animations` と `scripts.animate` を使う）。使うと定義ごと捨てられ、村人が透明になった
- `render_controllers` を空にしてはいけない。見えない物は `part_visibility` で全部隠す
- `getTopmostBlock` は、作物（当たり判定なし）の下の畑の土や、木の上の雪を返すことがある
- 見えないマーカーにも当たり判定が残る。`custom_hit_test` の当たり判定を地面の下に置き、チェストの上には置かない
- プレイヤーから離れたチャンクは止まる。村人は `getEntities` に出てこなくなる
- 動作確認はユーザーの実機（iPad）でしかできない。コンテンツログ（設定 → クリエイター）の `[error]` が一番の手がかり
