# ユーザーとのやり取り

- ユーザーは iPhone/iPad で遊び、確認する。返事は日本語で、手順はタップ操作で分かるように書く
- CSS で `var(--xx)` 形式は使わない（コピペで壊れる）。SyntaxError に注意する
- 機能を足したら README の説明とメニュー内の「遊び方」も更新する
- 公式マーケットプレイスでの販売を目指している（パートナー審査が必要。実験的機能は使わない）
- テスト用zipを更新したら、返事の最後に「テストで確認すること」を番号付きで書く。回答の無かった項目は、次回「前回未回答（未確認）」として書き足す
- 見た目はマイクラらしさ重視：人物は参考スキン風のリアル寄り（アニメ風は不可）、倉庫は普通のチェストの形。絵の見本は画像にして送ると判断が早い
- iPad ではエンティティをタップ＝攻撃になる。メニューを開く対象は、叩かれても音・赤い光・ダメージが出ないようにする
