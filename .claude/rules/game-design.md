# ゲーム仕様（決定済み）

- 販売方針：基本パック（無料・木こり）＋有料の職業パック（土木・農業・畜産・生産）。職業選択メニューで今後の職業を「近日公開」として見せる
- 最大Lv10。所持数 32→256、作業時間 1.0秒→0.3秒。体力 20→40（一番高い職業レベルで決まる。`blockai:hp_N` のコンポーネントグループ）
- 見た目は人間型（プレイヤーと同じ64x64配置）。キャラクター20人（男10・女10、体型 ふつう／ほっそり／マッチョ、`core/characters.js`）× 職業の衣装。転職しても人物はそのまま。村人メニュー「見た目を選ぶ」で変更
- 夜（13000〜23000）は荷物をしまってから、空いているベッドで寝る（`occupied_bit` と普通の村人が近くにいるベッドは避ける）。無ければ倉庫の前で休み、10秒ごとに新しいベッドを探し直す。休むと少しずつ回復、朝に全回復。寝ている間は `blockai:mode_sleep`（首を動かす行動なし）で、向きがずれたらベッドの向きに戻す
- 倒れたら持ち物を落とし、翌朝に倉庫の横で復活（「村の設定」でOFFにできる）。データは `blockai:roster`（控え）と `blockai:fallen`
- 経験値は職業ごと（`blockai:xp:<job>`）。職業を戻すと続きから
- 特技はLv5・8・10で覚える
  - 木こり：葉っぱ払い／植林名人（age_bit）／倒木（`blockai:falling_tree` の倒れるアニメーション）
  - 農家：豊作／緑の手（growth 3から）／一斉収穫（目の前3×3）
- 村長メニュー「村の設定」のテストモードで、全ての特技をLv1から使える
- 木こり：自然の葉（persistent_bit=false）が付いた木だけを切る。植え直しは作業設定でON/OFF
- 農家：新しく耕さない。空いた畑に、周りと同じ種だけをまく。種は倉庫から道具袋へ持ち出す（ニンジン・ジャガイモは設定でON）
- 村レベル（納品 500/2000/5000/10000）で半径が32→64に広がる。職業ごとの仕事場（半径8〜32）、立ち入り禁止エリアがある
- 村の倉庫：村レベルごとに 容量 54/108/216/432/864 マス、置ける数 1〜5個。中身は全倉庫で共有。重ねられない物（道具・防具）は入れない
- 「遠くにいても村を動かす」は初期ON（ティッキングエリアを使う）
- 未決定：パックを実際に分けるときの、パック間のやり取り（ダイナミックプロパティはパックごとに別）
